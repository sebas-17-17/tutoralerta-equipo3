## Ejecutar el .jar del proyecto
### Requisitos previos

*  Java JDK 17 o superior instalado y configurado en el PATH del sistema.

### Ejecución del proyecto

*  Ubicarse dentro de la carpeta dist del proyecto:
cd tutoralerta-equipo3/dist

* Ejecutar el archivo .jar:
java -jar tutoralerta-equipo3-1.0-SNAPSHOT.jar
